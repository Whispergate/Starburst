# C2 Profiles

Starburst supports four C2 profiles. Transport is selected at compile time - one profile per payload.

Egress profiles (direct communication with Mythic): HTTP, HTTPX, GitHub.

P2P profiles (relay through an egress agent): SMB, TCP, LLDP.
